cbmman is a human-friendly TUI for codebase-memory-mcp — index, query and monitor codebase graphs without hand-writing JSON tool calls. Two implementations: bash + tuish and Rust + ratatui.

Quick start

Make sure codebase-memory-mcp is installed and on your PATH (or set CBM_BIN).

codebase-memory-mcp --version
# Bash (tuish is vendored in ./tuish; auto-cloned if missing)
./cbmman.sh
# Rust
cargo install cbmman
cbmman

Non-interactive pass-through for scripting:

./cbmman.sh cli search_graph '{"project":"my-project","query":"order handler"}'
./cbmman.sh --version

Installation

Bash + tuish
  • bash 4+, python3
  • tuish vendored in tuish/ (1.3 MB) — no network on first run
  • Fallback: auto-clones from GitHub if tuish/ is deleted
git clone https://github.com/handyutils/cbmman
cd cbmman
./cbmman.sh
Rust + ratatui
  • Rust toolchain (cargo)
  • Crates: ratatui 0.29, crossterm 0.28
cargo install cbmman
cbmman
# or from source
cargo run --release

Binary also ships as ./cbmman next to cbmman.rs in ~/.scripts/codebase/.

CLI pass-through

For scripting, bypass the TUI:

./cbmman.sh cli search_graph '{"project":"p","query":"q"}'
./cbmman.sh cli index_status '{"project":"p"}'
./cbmman.sh --version
cbmman cli get_architecture '{"project":"p","aspects":["clusters"]}'

See codebase-memory-mcp for all tool names and args.
